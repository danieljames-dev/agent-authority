What each status means

🌐 Web · Reachable

A link returned HTTP 200 on a recorded check. That alone is not a functionality test.

⬇ Download · Locally opened

Downloaded HTML, opened from a local file, saw upload controls, and no page-script errors. Processing QA remains separate.

💻 Install · Independently verified

An actual signed/package installer or supported distribution with installation testing. Unknown until evidence exists.
